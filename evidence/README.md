# Доказательства и их ограничения

`legacy/` содержит карты импортов/строк и декомпиляции `bitcoin.exe` и `libeay32.dll`. `modern/` — выбранные декомпиляции Bitcoin Core 32.1, Mach-O metadata, imports и обезличенные результаты regtest. Полный dump строк приложен к релизу; ссылка и хеш — в `modern/strings-offsets.md`.

Эти файлы не являются исходным кодом Bitcoin или OpenSSL. Декомпилятор может ошибочно восстанавливать типы и имена; выводы отчёта опираются на совокупность машинного кода, строк, xrefs, официальных исходников и эксперимента. Имена без `FUN_...` в label-скриптах присвоены вручную.

В `modern/dynamic/qt-regtest.log` локальные абсолютные пути заменены на `$HOME` и `$LAB_DIR`; в `modern/import-analysis.log`, Mach-O metadata и entitlements локальные префиксы также обезличены. Технические записи не изменены. Опубликованный regtest-адрес относится к удалённому искусственному кошельку и не представляет ценности. `sqlite-summary.json` содержит только метаданные записей и их длины, не ключевые значения.

`legacy/ui.cpp` — рабочая копия раннего исходника, использованная для строковых ссылок. Она отличается от архивной только записью двух символов в workaround UTF-8; строки, участвующие в выводах, не затронуты.

Полные Ghidra-проекты и бинарники не включены. Для проверки адресов необходимо использовать файлы с точными хешами из `docs/artifact-hashes.md` и повторить анализ по `docs/methodology.md`.
